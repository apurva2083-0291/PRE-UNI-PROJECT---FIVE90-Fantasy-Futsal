# PROJECT-PRE-UNI-FIVE90

FIVE90 is a Python-based two-player fantasy futsal draft and match simulation game.

## Main Features

- Two-player local game
- Five-round footballer draft
- 1-2-1 futsal formation
- 24-player CSV database
- Plotly match visualization
- Virtual 90-minute match
- Goal scorers and final result

## Technologies

- Python
- Pandas
- Plotly
- Figma
- CSV
