# FIVE90 Final Testing Checklist

Run `python -m unittest discover -s tests -v` first. Then complete this short manual check.

- [ ] The title/name-entry window opens.
- [ ] Empty names and duplicate names are rejected.
- [ ] Five draft rounds appear in this order: GK, DEF, MID, MID, ATT.
- [ ] Each round offers four players.
- [ ] Both users select once per round.
- [ ] A selected footballer cannot be selected again.
- [ ] Both final teams contain exactly five unique players.
- [ ] Generated player cards show the correct template, photo, name, position, overall, and statistics.
- [ ] The match replay opens in the browser.
- [ ] Five blue and five red circles appear with player names.
- [ ] The ball and players move when the match is played.
- [ ] Minute, event text, and score update.
- [ ] Goal, half-time, and full-time overlays appear.
- [ ] The full-time screen shows the correct winner, score, and scorers.
- [ ] Rematch uses the same teams.
- [ ] New Draft returns to name entry and creates new teams.
- [ ] Exit closes the game without an error.
